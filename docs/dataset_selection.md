# Dataset Description

The IBM Telco Customer Churn dataset contains customer demographic information, subscribed telecom services, account details, billing information, and customer churn status.

The dataset is designed for binary classification problems where the objective is to predict whether a customer will discontinue telecom services.

---

# Reason for Selection

This dataset was selected because it:

- Aligns directly with the project objective.
- Represents a realistic business problem.
- Contains sufficient customer records for model training.
- Includes both categorical and numerical variables.
- Is widely recognized for benchmarking customer churn prediction models.
- Supports exploratory data analysis, feature engineering, classification modelling, and explainable AI techniques.

---

# Expected Outcome

Develop a Machine Learning model capable of accurately predicting customer churn and providing actionable business insights for customer retention.
